swap_horiz What changed?

  • Promisified the internal routing core.
  • Removed need for explicit try/catch blocks in async route handlers.
  • Updated error propagation logic.

lightbulb Why it matters

Historically, unhandled promise rejections in Express routes would crash the Node process. This refactor intercepts rejections automatically, routing them to the standard error-handling middleware, drastically improving default application stability.
