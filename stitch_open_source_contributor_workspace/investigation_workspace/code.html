BUG Issue #7427

router.use() mutates prototype chain improperly

schedule Opened 2 days ago account_circle Reported by @dev-user

info What is happening?

When registering middleware via router.use(), the router attempts to inherit the prototype of the mounted application to support specific routing behaviors. However, if multiple routers are nested or if middleware throws an error early in the chain, the original prototype is not properly restored. This leads to downstream middleware receiving a polluted `req` object, causing intermittent `TypeError: req.someMethod is not a function` exceptions under load.

Suggested Direction

The missing restoration occurs when router.handle yields an error abruptly. Investigate adding a `try/finally` block or attaching the restoration to an event listener on the response stream to guarantee execution.
